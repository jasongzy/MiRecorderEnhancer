<h1 align="center">小米录音机增强</h1>

[English Doc](README.md)

## ✨ 功能

- 条件筛选
  - 位置：本地、已同步或仅云端
  - 时长：少于或不少于任意秒数
  - 日期：任意日期范围
  - 文字转写状态：已转写或未转写
- 手动触发单条或批量文字转写

## 📥 安装

从 [GitHub Release](https://github.com/jasongzy/MiRecorderEnhancer/releases/latest) 下载 APK。

- Android 13 或更高版本
- 支持现代 Xposed API 的 LSPosed 环境
- 小米录音机：已在 `7.8.9.9` 上验证

安装后，在 LSPosed 中启用“小米录音机增强”并重启小米录音机。模块静态作用域为 `com.android.soundrecorder`。
